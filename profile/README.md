# Inttegro

**Commerce infrastructure for growing businesses.**

Build checkout, payments, orders, products, customers, refunds, payouts, and more with typed SDKs that feel native in your language.

[Get started in Inttegro Studio](https://studio.inttegro.com) · [Read the API reference](https://studio.inttegro.com/api) · [Explore integration examples](https://github.com/inttegro/inttegro-demos)

## Build with the API directly

The [Inttegro OpenAPI specification](https://github.com/inttegro/openapi) is the source for API contracts and code generation. For agent-assisted integration design, connect [Inttegro MCP](https://studio.inttegro.com/inttegro-mcp) and ask it to design an integration for your stack.

Questions or feedback? Open an issue in the relevant SDK repository.
